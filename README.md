### A DedSec logo splash screen for KDE Plasma 6
![](https://github.com/Mortal-Jelly/DedSec_Splash/blob/main/contents/previews/dedsec.gif)

Can be installed through built-in store by searching for DedSec (No need to download the zip).

### Manual Installs


Simply enter this in your console `git clone https://github.com/Mortal-Jelly/DedSec_Splash.git ~/.local/share/plasma/look-and-feel/DedSec`

Or can be manually installed by unzipping this file inside ~/.local/share/plasma/look-and-feel/

After installing, DedSec should appear under Splash Screen in your system settings
